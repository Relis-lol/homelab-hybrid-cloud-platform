# Credits & Compliance

Credits, contact information, and legal notices for the EVE Market Platform.

---

# 🎯 Purpose

Provide transparent attribution, project contact information, and required legal disclosures.

---

# 🛠️ Included Components

| Component         | Purpose                               |
| ----------------- | ------------------------------------- |
| Character Card    | Ingame contact information            |
| Credits Page      | Project attribution                   |
| CCP Disclaimer    | Intellectual property acknowledgement |
| AI Disclosure     | Generated content transparency        |
| Responsive Layout | Integrated dashboard section          |

---

# 🧱 Design Decisions

* Ingame contact only

  * avoids exposing personal information

* Legal information separated from gameplay tools

  * keeps the main interface uncluttered

* CCP ownership clearly acknowledged

  * aligns with fan-project expectations

* AI-generated content disclosed

  * improves transparency
